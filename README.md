# Run Locally

```bash
git clone https://github.com/BruceMorpho/purushoth_portfolio
cd purushoth_portfolio
pnpm install
pnpm dev
```

Then open http://localhost:3000. All the content is managed from [src/data/resume.tsx](./src/data/resume.tsx).
